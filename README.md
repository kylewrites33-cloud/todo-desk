# Kyle's To-Do Desk

A one-page web app for Kyle's to-dos. It holds no data. It reads and writes `todos.md` in a private repository through the GitHub API, using a key pasted into the app's Settings (kept in that browser only).

The master copy of `index.html` lives in the private `bpf-data` repo at `tracker/app/index.html`; keep the two the same.
